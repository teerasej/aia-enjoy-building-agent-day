# ไฟล์ประกอบและ Resources

ดาวน์โหลดชุดไฟล์ครั้งเดียว แล้วใช้หน้า Resources เพื่อตรวจผลลัพธ์ระหว่างทำแบบฝึกหัดครับ

## ดาวน์โหลด

- [ไฟล์ประกอบทั้งหมด](https://teerasej.github.io/aia-enjoy-building-agent-day/downloads/two-agent-workshop-sample-files.zip)

ภายใน ZIP มีไฟล์สำหรับทำแบบฝึกหัดตามนี้

### Meeting Action Follow-up Agent

- `project-northstar-reference-pack.docx` ใช้เป็น `Knowledge`
- `fictional-meeting-notes.md` ใช้วางใน `Test your agent`

### Claims Document Readiness Agent

- `fictional-claims-readiness-guide.docx` ใช้เป็น `Knowledge`
- `fictional-claim-form.docx` ใช้เป็นไฟล์แนบสำหรับการฝึก
- `fictional-itemized-receipt.pdf` ใช้เป็นไฟล์แนบสำหรับการฝึก
- `fictional-medical-certificate.pdf` ใช้เป็นไฟล์แนบสำหรับการฝึก
- `fictional-claim-submission.md` ใช้ตรวจรายละเอียดของ Claim Package และขอบเขตการใช้

หากไม่สะดวกใช้ ZIP สามารถดาวน์โหลดไฟล์แยกได้จากรายการด้านล่าง
